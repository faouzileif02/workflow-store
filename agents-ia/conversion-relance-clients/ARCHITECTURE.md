# Architecture — Conversion & Relance Clients

## Flux cible

`Trigger planifié`  
→ `Lire clients / commandes Shopify`  
→ `Calculer segments`  
→ `Filtrer exclusions`  
→ `Agent Conversion IA`  
→ `Choisir produit / message`  
→ `Contrôle règles marketing`  
→ `Validation si requise`  
→ `Email / SMS`  
→ `Enregistrer résultat`  
→ `Rapport KPI`

## KPI à suivre

- messages préparés ;
- messages envoyés ;
- clics si disponibles ;
- commandes attribuées si traçables ;
- chiffre d'affaires attribué si traçable ;
- taux de désinscription / erreur.

## État

Architecture définie. Workflow JSON à construire et tester avant commercialisation.
