# Agent IA Conversion & Relance Clients — Shopify + n8n

**SKU :** N8N-AI-CONVERT-020  
**Statut :** EN DÉVELOPPEMENT  
**Type :** Agent IA n8n

## Objectif

Identifier les opportunités de réachat et préparer des relances personnalisées à partir des données clients et commandes Shopify.

## Fonctions prévues

- segmentation par récence, fréquence et historique d'achat ;
- détection des clients inactifs ;
- choix d'un angle de relance ;
- recommandation d'un produit pertinent ;
- préparation email ou SMS personnalisé ;
- contrôle anti-spam / fréquence ;
- suivi des envois et résultats ;
- rapport de conversion.

## Garde-fous

- pas d'envoi sans consentement et règles compatibles avec le canal utilisé ;
- limite de fréquence ;
- liste d'exclusion ;
- validation humaine possible ;
- journalisation de chaque message.
