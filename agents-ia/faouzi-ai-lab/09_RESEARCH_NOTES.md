# Research Notes — Existing 2026 Areas to Avoid Cloning

These notes summarize areas checked before selecting the ideas in this folder.

## Already active categories

Generic versions of these ideas are already active in the ecosystem: time-travel/replay debugging, chaos engineering, failure memory, tool-call deduplication, context pruning, portable agent state, least-privilege permission proxies, reversibility layers and semantic version metadata.

## Differentiation chosen here

| Existing category | Faouzi AI Lab angle |
|---|---|
| Permissions | Permission expires when **purpose** changes |
| Logging / approvals | Compare **predicted effect vs actual effect** |
| Prompt management | Build a **Prompt Bill of Materials** |
| Agent evals | Mutate **user intent** and assert behavioral invariance |
| SemVer | Infer version bump from **measured behavior** |
| HITL | Quantify **Approval Debt** |
| Prompt constraints | Compile constraints into an external **Intent Lockfile** |
| Trace replay | Use replay specifically for **model substitution risk** |

## Rule before publishing standalone projects

Repeat GitHub research using the exact project name, one-line pitch, core mechanism, synonyms, GitHub Topics and repositories published in the previous 30 days.

Open-source moves quickly. A gap visible today can be filled tomorrow.
