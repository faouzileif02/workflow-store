# Architecture — Directeur Marketing & Ventes

## Flux cible

`Trigger planifié`  
→ `Charger configuration`  
→ `Lire catalogue Shopify`  
→ `Lire ventes / KPIs`  
→ `Directeur Marketing IA`  
→ `Décider des priorités`  
→ `Router vers sous-agents`  
→ `Validation humaine si nécessaire`  
→ `Exécuter actions autorisées`  
→ `Journaliser`  
→ `Rapport final`

## Sortie du Directeur IA

Format structuré attendu :

- produit prioritaire ;
- objectif ;
- canal ;
- action proposée ;
- justification ;
- niveau de confiance ;
- risque ;
- besoin de validation humaine ;
- KPI à suivre.
