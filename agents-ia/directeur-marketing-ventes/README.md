# Agent IA Directeur Marketing & Ventes — Multi-Agent n8n

**SKU :** N8N-AI-MKT-DIR-018  
**Statut :** EN DÉVELOPPEMENT  
**Type :** Agent IA n8n multi-agent

## Objectif

Créer un **directeur marketing virtuel** qui analyse le catalogue et les performances commerciales, choisit les priorités et délègue les tâches à des agents spécialisés.

## Fonctions prévues

- lecture du catalogue Shopify ;
- analyse des ventes et signaux de performance ;
- sélection des produits à mettre en avant ;
- plan marketing journalier / hebdomadaire ;
- création de briefs pour SEO, contenu, email et réseaux sociaux ;
- centralisation des résultats ;
- recommandations d'optimisation ;
- validation humaine avant action sensible.

## Sous-agents prévus

- Agent Analyse Produit ;
- Agent SEO ;
- Agent Copywriting ;
- Agent Email Marketing ;
- Agent Social Media ;
- Agent Conversion ;
- Agent Reporting.

## Pré-requis envisagés

- n8n ;
- Shopify Admin API ;
- fournisseur LLM via credentials n8n ;
- Google Sheets ou base de données pour le suivi ;
- email / messagerie selon les canaux choisis.

## Garde-fous

L'agent ne doit pas modifier seul les prix, lancer une remise, publier une campagne ou envoyer un grand volume de messages sans règle d'autorisation.
