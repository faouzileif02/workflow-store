## Objectif

Analyser les fiches Shopify et préparer des optimisations qui améliorent la clarté, le référencement et la conversion.

## Fonctions prévues

- lecture titre, description et données produit ;
- diagnostic de la fiche ;
- proposition d'un titre optimisé ;
- description orientée bénéfices client ;
- FAQ produit ;
- arguments de vente ;
- meta title et meta description ;
- détection des informations manquantes ;
- version avant/après ;
- validation humaine avant mise à jour Shopify.

## Règle essentielle

Par défaut, l'agent **prépare** les modifications mais ne les publie pas directement. La mise à jour Shopify passe par une validation explicite.
