# Architecture — Agent SEO & Fiches Produits

## Flux cible

`Trigger manuel / planifié`  
→ `Lister produits Shopify`  
→ `Filtrer produits à auditer`  
→ `Agent SEO / Conversion`  
→ `Validation JSON structurée`  
→ `Comparer original / proposition`  
→ `Approbation humaine`  
→ `Mise à jour Shopify optionnelle`  
→ `Log résultat`

## Données de sortie

- score de complétude ;
- problèmes identifiés ;
- titre proposé ;
- description proposée ;
- bénéfices ;
- FAQ ;
- meta title ;
- meta description ;
- mots-clés ;
- statut APPROUVÉ / À REVOIR.

## État

Architecture définie. Workflow JSON à construire et tester avant commercialisation.
