## Workflow disponible

### Alerte automatique rupture de stock Google Sheets

Surveille chaque matin les niveaux de stock dans Google Sheets et envoie un email lorsque des produits atteignent leur seuil critique.

**Technologies :** n8n, Google Sheets, Gmail  
**Catégorie :** E-commerce / Gestion de stock  
**Statut :** publiable

Voir : `ecommerce/alerte-rupture-stock-google-sheets/`

> Le fichier JSON commercial complet n'est pas exposé dans le catalogue public.
