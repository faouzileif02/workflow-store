# Installation — Facebook Posts + Reels

1. Importer `Facebook-Posts-et-Reels-Template-Clean.json` dans n8n.
2. Sélectionner les Data Tables de votre propre instance.
3. Renseigner votre propre page Facebook dans les nœuds de configuration.
4. Reconnecter le modèle IA et Facebook avec vos propres credentials n8n.
5. Remplacer les images et vidéos d'exemple par vos propres médias.
6. Tester séparément la branche **Post Facebook normal** et la branche **Reel Facebook**.
7. Activer les déclencheurs uniquement après les tests.

## Sécurité

Ne placez jamais de clé API, token ou mot de passe directement dans les champs du workflow. Utilisez les credentials sécurisés de n8n.
